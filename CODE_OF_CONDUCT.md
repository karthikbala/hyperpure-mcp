# Community conduct

Treat contributors and users with respect. Discuss ideas and code constructively; give people room to ask questions and learn. Harassment, threats, discriminatory remarks, personal attacks and publishing another person's private information are not acceptable.

Maintainers may edit or remove harmful content, close disruptive discussions, or restrict participation. Enforcement should be proportionate and explained when doing so does not expose private information. These expectations apply to the repository's issues, pull requests, discussions and other project spaces.

Use GitHub's reporting controls for abuse. For a concern that requires private maintainer contact, request a private channel without posting sensitive details. Security vulnerabilities belong in the process described in [SECURITY.md](SECURITY.md).
